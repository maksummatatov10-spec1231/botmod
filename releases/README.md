# Releases — готовые сборки мода

Сюда CI кладёт **собранный jar** после каждого зелёного `build`.

| Файл | Что это |
|---|---|
| `botmod-<version>.jar` | основной мод: бот, арены, `/duel` |
| `kitmod-<version>.jar` | редактор китов с GUI (отдельный мод) |
| `build-info.txt` | что лежало в `build/libs` при сборке |

## Как установить

1. Положить jar в `.minecraft/mods/` (можно оба — они независимы).
2. Нужен Fabric Loader 0.20.1+ и Fabric API 0.166.2+26.3.
3. Запустить Minecraft 26.3.

## Проверка

- jar собран той же конфигурацией, что проходит GameTest в CI;
- вместе с jar в репозитории лежат скриншоты настоящего клиента (`docs/screenshots/`)
  и логи прогона (`docs/tests/ci/`).

> Файлы перезаписываются при каждой успешной сборке — здесь всегда последняя версия.
