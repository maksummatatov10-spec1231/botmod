# BotLab — личная лаборатория тестирования

BotLab — это дашборд, который показывает **всё, что происходит с ботом**:
телеметрию, кадры игры, графики FPS/TPS, журнал событий и статистику «обучения».

```
lab/
├── server.py     ← HTTP-сервер (stdlib, без зависимостей)
├── index.html    ← разметка дашборда
├── app.js        ← логика: опрос, графики, команды
├── style.css     ← стили (без CDN, всё локально)
├── frames/       ← кадры (синтетика или кадры от мода)
└── reports/      ← отчёты сценариев (smoke/combo/defense)
```

## Запуск

```bash
python3 lab/server.py --port 8099 --fps 1
# открыть http://localhost:8099
```

Флаги: `--mc <url>` — адрес телеметрии мода (по умолчанию `http://127.0.0.1:17777`),
`--fps <n>` — кадров в секунду, `--record` — сразу начать запись.

## Откуда берутся данные

| Источник | Endpoint | Что отдаёт |
|---|---|---|
| Мод (сервер) | `GET 127.0.0.1:17777/api/state` | TPS, тики, боты (режим, kit, HP, позиция, агрессия, попадания), события |
| Мод (сервер) | `POST 127.0.0.1:17777/api/command` | `spawn / mode / kit / duel / stop / remove` |
| Мод (сервер) | `GET 127.0.0.1:17777/api/ping` | «мод жив» |
| Мод (клиент) | `POST <lab>/api/frame` | готовый PNG-кадр игры (1 кадр/сек по умолчанию) |
| BotLab | `GET /api/state` | объединённый снимок для дашборда |
| BotLab | `GET /api/plan` | стадия проекта из `docs/03-plan-and-status.md` |
| BotLab | `GET /api/screenshots` | скриншоты настоящего клиента из `docs/screenshots/` |
| BotLab | `POST /api/scenario` | сценарий `smoke / combo / defense` → отчёт в `lab/reports/` |

Если мод не запущен — BotLab работает на **mock-данных** (пилл «○ симуляция»),
как только мод отвечает — переключается на реальные (пилл «● мод подключён»).

## Кадры: два режима

1. **Синтетика** — когда игры нет: BotLab рисует кадр сам (небо/земля/бот).
2. **Настоящие** — клиент мода каждую секунду снимает кадр
   (`Screenshot.takeScreenshot(mainRenderTarget, downscale, callback)`),
   кодирует в PNG и шлёт `POST /api/frame` из фонового потока.

Настройки в `config/botmod.json` или командой в игре:

```
/bot lab                     → показать текущие настройки
/bot lab on|off              → включить/выключить отправку кадров
/bot lab http://host:port    → направить кадры и телеметрию на другую лабораторию
```

## Сценарии

| Сценарий | Что делает |
|---|---|
| `smoke` | спавнит бота, ждёт, проверяет что жив, останавливает |
| `combo` | спавнит `rush`-бота, запускает дуэль, ждёт, снимает HP |
| `defense` | спавнит `defender`-бота, запускает дуэль, проверяет блок |

Отчёт: `lab/reports/<сценарий>-<время>.md` + JSON.

## Дашборд

- пилюли: источник (мод/симуляция), REC, FPS, TPS;
- графики FPS и TPS (canvas, 90 точек);
- карточки ботов: режим, kit, позиция, HP-бар, **агрессия**, попадания/пропущенные;
- панель команд: спавн, режим, kit, дуэль, стоп, удаление;
- просмотр кадра + лента последних кадров;
- журнал событий (спавн, урон, дуэль, ошибки);
- **стадия проекта** — читается из `docs/03-plan-and-status.md`;
- **галерея скриншотов** из CI (`docs/screenshots/`).
