# Арены и дуэли

## Что это

Второй режим игры: **дуэль на арене в отдельном мире**. Игрок выбирает арену,
настраивает поведение бота и переносится на один конец арены — бот появляется
на противоположном.

## Измерение

`botmod:arena` — отдельный void-мир (свой `dimension_type`, плоский генератор,
без мобов и террейна). Файлы:

```
src/main/resources/data/botmod/dimension_type/arena.json
src/main/resources/data/botmod/dimension/arena.json
```

## Размеры и устройство арены

У всех арен одинаковые размеры:

| Параметр | Значение |
|---|---|
| Длина (X) | 300 блоков |
| Ширина (Z) | 180 блоков |
| Высота стен | 24 блока |
| Пол | 4 слоя блоков стиля (3 основания + верхний) |
| Стены | 2 слоя барьера по периметру |
| Потолок | 2 слоя барьера |
| Колонны | 3×3 по четырём углам внутри |

Спавны: игрок в `x = -140`, бот в `x = +140` (по длине), `y = 64`, `z = 0`
(каждая арена сдвинута по Z на 1000 блоков).

## Шесть стилей

| Стиль | Пол | Акцент | Колонны |
|---|---|---|---|
| `end` Энд | эндерняк | пурпур | обсидиан |
| `desert` Пустыня | песчаник | красный песок | песчаник |
| `nether` Незер | незеррак | чёрный камень | базальт |
| `ice` Лёд | лёд | синий лёд | кварц |
| `jungle` Джунгли | трава | мох | джунглевое бревно |
| `ocean` Океан | призмарин | тёмный призмарин | морской фонарь |

## Меню `/duel`

Открывает сундук 6 рядов:

```
ряд 1: [Энд][Пустыня][Незер][Лёд][Джунгли][Океан]
ряд 2: [Кит] [Сложность]
ряд 3: [Спринт][Зелья][Криты][Щит][W-tap][Прыжки]
ряд 4: [Как играть]
ряд 6: [▶ Начать дуэль]
```

Клик по иконке арены — выбор. Кит и сложность переключаются по кругу.
Каждый поведенческий тумблер переключает состояние (ВКЛ/ВЫКЛ) прямо в меню.

### Настройки бота

| Настройка | Что делает |
|---|---|
| Спринт | бот бегает спринтом на дальней дистанции |
| Зелья | пьёт зелье лечения при HP < 45% (кулдаун 15 сек) |
| Криты | крит-прыжки в бою, урон ×1.5 в падении |
| Щит | поднимает щит в ближнем бою |
| W-tap | короткий отход сразу после попадания |
| Прыжки | прыжки при стрейфе |

### Сложность

| Уровень | Скорость | Урон | Реакция (тики) | Агрессия |
|---|---|---|---|---|
| Лёгкий | ×0.85 | ×0.80 | 20 | 0.85 |
| Обычный | ×1.00 | ×1.00 | 14 | 1.00 |
| Сложный | ×1.12 | ×1.15 | 9 | 1.20 |
| Эксперт | ×1.22 | ×1.35 | 5 | 1.40 |

## Правила арены

- Ломать и ставить блоки **нельзя** — события отменяются во всём измерении.
- После смерти бота или игрока дуэль заканчивается, игрок возвращается на
  прежнее место.
- Выход из арены (например, командой) тоже завершает дуэль.

## Команды

```
/duel                 открыть меню
/duel start <арена>   сразу начать бой (end|desert|nether|ice|jungle|ocean)
/duel stop            завершить дуэль и вернуться
```
