# Как проверить мод у себя на ПК

Два пути: **быстрый** (готовый jar) и **из исходников** (для разработки).

---

## 1. Быстрый: готовый jar

1. Скачайте [`releases/botmod-0.1.0.jar`](../releases/botmod-0.1.0.jar).
2. Установите **Minecraft 26.3** + **Fabric Loader 0.20.1**.
3. Положите в `.minecraft/mods/`:
   - `botmod-0.1.0.jar`
   - `fabric-api-0.166.2+26.3.jar` (Fabric API — обязателен)
4. Запустите игру.

Проверка в игре:

```
/bot list                       → пусто
/bot spawn sparring diamond_sword
/bot duel
```

Должен появиться бот, который подбегает и бьёт. HUD в левом нижнем углу показывает
режим, здоровье и агрессию.

## 2. Из исходников

```bash
git clone https://github.com/maksummatatov10-spec1231/botmod.git
cd botmod
git checkout arena/1c3d49ae-botmod

./gradlew runClient        # запустить игру с модом
./gradlew build            # сборка + серверные GameTest
./gradlew runProductionClientGameTest   # клиентский GameTest (скриншоты)
```

Нужен **JDK 25**. Loom сам скачает Minecraft 26.3 и зависимости.

---

## 3. Подключить лабораторию

Лаборатория — это дашборд, который показывает телеметрию и кадры игры.

```bash
# в отдельном терминале, из корня репозитория
python3 lab/server.py --port 8099
```

Откройте <http://localhost:8099>.

Затем в игре направьте мод на лабораторию:

```
/bot lab http://127.0.0.1:8099
```

Теперь:
- дашборд покажет реальных ботов, HP, агрессию, события урона;
- клиент начнёт слать **1 кадр в секунду** в дашборд (пилл «● мод подключён»);
- кнопки «Спавн / Режим / Кит / Дуэль» в дашборде управляют ботом в игре.

Отключить кадры: `/bot lab off`. Посмотреть настройки: `/bot lab`.

> Если игра и лаборатория на разных машинах — укажите вместо `127.0.0.1` адрес машины
> с лабораторией и откройте порт 8099.

---

## 4. Сценарии автопроверки

В дашборде: «Сценарий» → `smoke / combo / defense`.
Отчёт появится в `lab/reports/`.

Или через HTTP:

```bash
curl -X POST localhost:8099/api/scenario -d '{"name":"smoke"}'
```

---

## 5. Что должно работать

| Проверка | Ожидание |
|---|---|
| `/bot spawn` | бот появляется перед игроком, лицом к нему |
| `/bot duel` | бот бежит к игроку, стрейфит, наносит урон |
| HUD | панель «Training Bot · режим · агрессия · HP» |
| `/bot lab <url>` | в дашборде появляются реальные данные и кадры |
| `H` | включает/выключает HUD |

Если что-то не так — откройте `logs/latest.log` и `lab/reports/`, там видно всё.
