| Библиотека | Почему |
|---|---|
| **PlayerAnimator** | **нет сборки под 26.3** (пусто на Modrinth). Альтернатива — свои анимации через `KeyframeAnimations` или GeckoLib. |

## 3. Тематические моды-референсы

### 3.1. HeroBot — ближайший по идее проект

| Параметр | Значение |
|---|---|
| Автор | herobane |
| Modrinth | `wt23fpWX`, **1.88 млн** загрузок, 269 подписчиков |
| Последний релиз | `1.21.11-1.4.3` (16 марта 2026) |
| Поддержка 26.x | **нет** (в исходниках есть ветка `26.2`, не выпущена) |
| Лицензия | **CC-BY-NC-4.0** — некоммерческая, с указанием авторства |
| Среда | только сервер, клиент не обязателен |
| Суть | фреймворк **фейковых игроков** (`ServerPlayer`), управление командами |
| Конфликт | несовместим с Carpet и Carpet PVP |

Что внутри (полезно подсмотреть):
- **Action packs**: `attack`, `swing`, `jump`, `move`, `look`, `sneak`, `sprint`, `use`, `hotbar`, `itemCd`.
- **Ping-симуляция**: задержка удара/использования на N мс, конвертация в тики (`botPingToTicks`).
- **Auto-jump** и работа с копьём — то, чего нет у Carpet.
- **Скины по частям** (`cape`, `jacket`, `leftSleeve`…), лево/праворукость.
- **Скриптовый AI**: блочная система (`AiScript`, `BlockDef`, `Wire`, `AiHexCodec`) — визуальные блоки логики.
- **Точная математика**: `/distance` (сферически/горизонтально/вертикально, `fromHitbox`, экспонента), `/delayed tickDelay`.
- Настройки боя: `shieldStunning`, `noProjectileRandom`, `botLagAttacks`.

Почему **не** берём его как зависимость:
1. Лицензия **NC** — в наш мод его код вставлять нельзя.
2. Нет 26.3 — только 1.21.11.
3. Это «консольный фреймворк», а нам нужны режимы тренировки, HUD и клиентская часть.
4. Несовместим с Carpet — сразу сужает круг пользователей.

Что забираем в архитектуру: идею **fake player** как «продвинутый режим» и **ping-симуляцию** для честной тренировки.
