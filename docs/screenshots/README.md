# Скриншоты настоящего клиента

Все кадры сняты **реальным Minecraft 26.3** в GitHub Actions
(Mesa llvmpipe, SDL offscreen, 854×480). Это не макеты — это вывод игрового рендера.

| Файл | Что на кадре | Когда снят |
|---|---|---|
| `0000_botmod-world.png` | Мир после прогрузки: небо, трава, хотбар, рука игрока | сразу после `waitForChunksRender()` |
| `0001_botmod-bot.png` | Бот перед игроком (крипер-скин), щит в руке, HUD-панель | после `/bot spawn sparring diamond_sword` + 20 тиков |
| `0002_botmod-duel.png` | **Дуэль**: крипер-бот с зелёными глазами, алмазный меч и щит, у игрока осталось 2 сердца | после `/bot duel` + 40 тиков |
| `0003_botmod-hud.png` | Тот же бой, кадр HUD | конец теста |
| `0004_botmod-arena.png` | Арена «Энд» в отдельном измерении: пол из эндерняка, барьерные стены | после `duel start end` |

## Скин бота

Бот использует скин, присланный пользователем (`docs/skins/training_bot_source.png`,
репозиторий `main`, файл `f25cda07d206d319.png`) — крипер-скин: чёрная база,
зелёные глаза, надпись CREEPER.

Особенность: в исходном скине область «шляпы» (hat layer, 32,0–64,16) была залита
непрозрачным чёрным и закрывала лицо. Инструмент
`python3 tools/skin_clear_hat.py` делает её прозрачной — после этого глаза видны.

## О чём говорят эти кадры

- Мод **загружается в настоящем клиенте** 26.3 и не роняет игру.
- Сущность бота **рендерится** с нужным скином, слоями брони и предметами в руках.
- HUD **рисуется поверх игры** и не ломает интерфейс.
- Бой **идёт**: бот сближается, стрейфит и снимает игроку HP.

## Как они получаются

```java
context.takeScreenshot("botmod-bot");   // Fabric Client GameTest API
```
→ `build/run/clientGameTest/screenshots/` → CI коммитит в `docs/screenshots/`.

## Ограничения

Рендер программный (llvmpipe): без сглаживания, с низким FPS, звук и рассказчик
отключены. Это подтверждение работоспособности, а не красота.
