# Скриншоты настоящего клиента

Все кадры сняты **реальным Minecraft 26.3** в GitHub Actions (Mesa llvmpipe,
SDL offscreen, 854×480). Это не макеты — это вывод игрового рендера.

| Файл | Что на кадре | Когда снят |
|---|---|---|
| `0000_botmod-world.png` | Мир после прогрузки: небо, трава, хотбар, рука игрока | сразу после `waitForChunksRender()` |
| `0001_botmod-bot.png` | Бот перед игроком: модель, скин, HUD-панель «Training Bot / Sparring · агрессия» | после `/bot spawn sparring diamond_sword` + 20 тиков |
| `0002_botmod-duel.png` | Дуэль: бот сошёл с места (стрейф), у игрока сняты сердца | после `/bot duel` + 40 тиков |
| `0003_botmod-hud.png` | Тот же бой, кадр HUD | конец теста |

## Как они получаются

```java
context.takeScreenshot("botmod-bot");   // Fabric Client GameTest API
```
→ `build/run/clientGameTest/screenshots/` → CI коммитит в `docs/screenshots/`.

## Скин бота

Бот использует скин, присланный пользователем (`docs/skins/training_bot_source.png`,
репозиторий `main`, файл `f25cda07d206d319.png`) — крипер-скин: чёрная база, зелёные глаза,
надпись CREEPER. Формат — стандартный скин игрока 64×64, поэтому он ложится на
`HumanoidModel` без правок UV.

## О чём говорят эти кадры

- Мод **загружается в настоящем клиенте** 26.3 и не роняет игру.
- Сущность бота **рендерится** (модель игрока, своя текстура, слои брони/предмета).
- HUD **рисуется поверх игры** и не ломает интерфейс.
- Бой **идёт**: бот двигается и наносит урон (у игрока ушло 4 сердца).

## Ограничения

Рендер программный (llvmpipe): без сглаживания, с низким FPS, звук и рассказчик отключены.
Это подтверждение работоспособности, а не красота.
