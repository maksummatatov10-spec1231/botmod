# Kit Editor (kitmod) — редактор китов

Отдельный мод для Minecraft **26.3 / Fabric**. Позволяет собрать кит в графическом
меню (как на серверах) и сохранить его в файл, который потом можно передать
PvP-боту или другу.

## Установка

1. Скопировать `releases/kitmod-0.1.0.jar` в `.minecraft/mods/`.
2. Нужен Fabric Loader 0.20.1+ и Fabric API 0.166.2+26.3.

## Команды

| Команда | Что делает |
|---|---|
| `/kit create <название>` | создаёт кит и открывает большой редактор |
| `/kit edit <название>` | открывает редактор существующего кита |
| `/kit <название> save` | сохраняет кит на диск |
| `/kit <название> delete` | удаляет кит |
| `/kits` | меню всех китов |

## Как устроено меню

**Редактор кита** — большой сундук (6 рядов):

- верхний ряд: левая рука, шлем, нагрудник, поножи, ботинки;
- остальные 4 ряда — инвентарь 36 слотов;
- всё остальное залито серым стеклом (разделители);
- при закрытии меню содержимое сохраняется автоматически.

**Меню китов** (`/kits`) — иконки всех китов + кнопка «＋ Создать кит».
Клик по киту открывает его настройки.

**Настройки кита**:

| Кнопка | Действие |
|---|---|
| Название | закрывает меню, следующее сообщение в чате становится названием |
| Иконка | открывает выбор предмета из инвентаря |
| Содержимое | большой редактор инвентаря |
| Левая рука | отдельное меню: один слот в центре |
| Броня | отдельное меню: 4 слота |
| Сохранить | пишет файл на диск |
| Удалить | удаляет кит |

## Где лежат киты

```
config/kitmod/kits/<id>.json
```

JSON, читаемый глазами: `id`, `name`, `icon`, `offhand`, `inventory[36]`, `armor[4]`.
Эту папку можно скопировать и передать кому угодно — ничего не потеряется.

## Разработка

```bash
./gradlew -p kitmod build
```

Код: `kitmod/src/main/java/com/kitmod/`
